presently seeing in the simulation. Copilot's image feature modules (`feature-image-engine.js`,
`feature-image-ui.js`, `image-core.js`) are deleted in the strip but remain recoverable from the
upstream fork history if this is ever picked up. User note: "just novelty, not a big thing I really
